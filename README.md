# 🧠 Operaciones Lógicas con Arduino

Este proyecto implementa **operaciones lógicas básicas** (AND, OR, NOT, XOR, etc.) usando **Arduino**, botones físicos y un LED.

---

## 🔧 Componentes

- 1x Arduino UNO
- 2x Botones
- 1x LED
- 3x Resistencias de 10kΩ
- Cables y protoboard

---

## ⚙️ Operaciones soportadas

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

---

## 🧪 Funcionamiento

Dependiendo de qué botones se presionan, se activa o no el LED para representar la salida de una operación lógica. Las combinaciones posibles te permiten simular puertas lógicas reales de forma física.

---

## 📁 Archivo principal

- `Operacionales.ino`: contiene el código fuente del proyecto en Arduino.

---

## 🚀 Cómo empezar

1. Abre `Operacionales.ino` en el IDE de Arduino.
2. Conecta los componentes según el esquema (ver código).
3. Carga el programa al Arduino.
4. Prueba diferentes combinaciones de botones.
